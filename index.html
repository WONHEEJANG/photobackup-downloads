설치하고 연결하기

  1. Mac 수신기 설치. 아래 DMG를 열고 수신기 앱을 응용 프로그램 폴더로 옮깁니다.
  2. 저장 디스크 연결. 수신기 앱을 열면 연결 창이 나타납니다. 외장 디스크를 선택하고 수신을 시작하세요.
  3. iPhone 연결. 내부 테스터는 초대받은 TestFlight에서 iPhone 앱을 설치할 수 있습니다. 두 기기를 같은 Wi-Fi에 연결하세요. 백업 탭에서 ‘QR로 맥 연결’을 누르고 맥 수신기에 표시된 QR을 스캔하세요.

구글 포토

  1. ☁️Takeout
  2. 💽맥·SSD
  3. 📱갤러리
  1. Google Takeout에서 Google 포토를 내보내고 맥에서 압축을 풉니다.
  2. 압축을 푼 폴더를 SSD 기본 보관함에 가져옵니다. 현재 이 단계는 맥 터미널에서 진행합니다.
  3. 아이폰 앱의 백업 → 갤러리 불러오기 → 한번에 불러오기를 눌러 목록과 미리보기를 받습니다.
Google Takeout 열기 ↗
맥에서 가져오는 명령

프로젝트의 photo_library.py와 photo_receiver.py가 있는 폴더에서 실행하세요. 두 경로는 실제 SSD와 압축 푼 폴더로 바꿉니다.

SSD_VOLUME='/Volumes/내 SSD' python3 photo_library.py import-takeout '/경로/Takeout/Google Photos'

iCloud · 아이폰 사진

  1. ☁️iCloud
  2. 📱사진 원본
  3. 💽맥·SSD
  1. iCloud에만 있는 원본은 Wi-Fi에서 받습니다. 아이폰 설정 → Apple 계정 → iCloud → 사진 → 다운로드 및 원본 유지를 선택합니다.
  2. 앱에서 사진 전체 접근을 허용하고 백업 → 사진 보관함 → 전체 보관함 백업을 누릅니다.
  3. 갤러리에서 백업 완료 표시를 확인합니다.

Mac 수신기 다운로드

Mac as Photo Vault Receiver 0.2.9 베타 · Apple Silicon · macOS 27.2 이상 · Python 3 필요

Mac용 DMG 다운로드 ↓

VP9 동영상 미리보기를 만들려면 맥에 FFmpeg가 필요합니다. Homebrew를 쓰는 경우 터미널에서 brew install ffmpeg를 실행하세요.

Mac 수신기는 Apple Developer ID 서명과 공증을 완료했습니다. iPhone 앱은 TestFlight 내부 테스터 초대가 필요합니다.
